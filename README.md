# 🌍 nuTerra (2014 archive)
 
*Visualizing a sustainable future.*
 
Concept website for **nuTerra**, a team project from the **Singularity University Graduate Studies Program** (NASA Research Park, summer 2014). In the program's 10 weeks, small teams designed technology ventures aimed at improving the lives of a billion people. The site originally lived at nuterra.io.
 
▶️ **[Watch the nuTerra pitch video](https://vimeo.com/104342427)**
 
nuTerra was a set of tools that **turn satellite imagery into usable metrics**. It combined data streams, including **hyperspectral imaging**, to quantify things like toxins in algal blooms, forest change, soil contamination and the extent of illegal mining. The goal was to give anyone frequently updated environmental data to raise awareness, inform decisions and support stewardship.
 
The site was a quick static prototype: HTML, CSS and JavaScript, with map layers for hyperspectral data built on [Derek Eder's Fusion Table Map Template](https://github.com/derekeder/FusionTable-Map-Template).
 
> Archived. Kept for history. Google Fusion Tables was shut down in 2019, so the map layers no longer work.
